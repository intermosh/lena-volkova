# lena-volkova
Lena Volkova es un caso de estudio de cómo codificar autoría en un flujo de generación de imagen con
IA: no como firma superficial sino como procedimiento de decisión con criterios falsables. El proyecto
ilustra que el problema central del medio —el promedio sin autor— es atacable por diseño, y ofrece un
patrón replicable (perfil + proceso + rúbrica + settings) para otras personas virtuales disciplinadas.

Su coautoría humana y de IA es, asimismo, una demostración práctica de la tesis de Zylinska: la
creatividad humana siempre fue técnica; lo nuevo es que ahora la técnica puede discutir sus propias
reglas.
